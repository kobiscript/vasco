VASCO DA LOR — STATIC MULTI-PAGE WEBSITE

This site is plain HTML, CSS, and a small JavaScript helper. It does not use
React, Next.js, npm, or ChatGPT.

PAGES
- index.html       Home
- players.html     Zidane, Maya, Seth, and Samory
- pathway.html     Development stages and coaching method
- tiers.html       Tier 1, Tier 2, and Tier 3
- accelerant.html  Private 10-month IQ, strength, and technique program
- film-room.html   Full private clips and embedded official match film
- contact.html     Application, phone, and email

SHARED FILES
- styles.css       Complete responsive design
- site.js          Video previews, progression filters, and seasonal pricing tabs
- media/           Images and local MP4 training clips
- og.png           Social-sharing image

MEDIA ORGANIZATION
The strongest added Zidane photographs have clean descriptive filenames such
as zidane-youth-training.jpg, zidane-chile-dribble.jpg, and
zidane-nycfc-signing.jpg. Original UUID-named uploads remain in media/ as a
preserved source archive.

PREVIEW
Double-click index.html, or run this command inside the folder:

  python3 -m http.server 8080

Then open:

  http://localhost:8080

DEPLOY
Upload this entire folder to any normal web server, cPanel host, Netlify,
Cloudflare Pages, or GitHub Pages. Keep all files and the media folder together.
